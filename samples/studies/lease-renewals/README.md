# Lease renewals sample

Sample data for the Studies walkthrough: [docs/studies-walkthrough.md](../../../docs/studies-walkthrough.md).

- `lease-renewals.csv`: 600 leases (2022–2025) and whether each renewed.
- `occupancy.csv`: 48 months of occupancy.
- `regional-rental-market-2026.md`: a market report to add as a document.
- `generate.py`: regenerates both CSV files (seeded; the effects built in are listed at its top).
