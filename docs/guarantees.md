# What the runtime guarantees

These hold **whatever the model decides**. Each is enforced by runtime code the LLM can't see
around: there's no tool to change a budget, a permission, a policy or another organization's data,
and messages between agents are treated as untrusted input. Each row names the enforcing code and
the tests that prove it. `src/` paths are relative to the repository root.

## What is *not* guaranteed

- **Audit records are tamper-evident, not tamper-proof.** Someone with write access to the
  database could rewrite a whole chain; export head hashes elsewhere if that matters
  ([safety.md](safety.md)).
- **The outcome of an interrupted non-idempotent call is unknown**, by design. It's reported, not
  guessed.
- **Estimates are estimates.** The preview ([preview.md](preview.md)) predicts cost; the budget is
  what's enforced.
- **A replay is decision-for-decision**, not timing-for-timing. Agents running concurrently can
  interleave differently, but each one makes the same decisions after the same inputs.
- **Model output quality** isn't a runtime guarantee. It's measured ([evals.md](evals.md)).

## Compared with a single-operator gateway

A personal gateway such as OpenClaw has one trust domain per gateway: whoever runs it can reach
everything in it. Aktor isolates organizations *inside one runtime*. Messaging, discovery, memory,
SQL, the API and every protocol endpoint enforce the same boundary, and the rows above are tested
at each of those layers.
